# Бот «Новости исламского мира» — @ilm4_info

## Как устроено (всё на серверах)
- **Источники**: 36 источников (сайты, Telegram и X) по странам (сайт + Telegram), собраны по каналу @ilm4_info и советам шейха. Al Jazeera и другие антисаудовские — в чёрном списке. Меняются в начале bot.py.
- **Редактор — Claude в облаке** (routine по подписке, раз в 1–2 часа): находит новости,
  точно переводит, пишет посты по `rules.md`, сам проверяет их и кладёт черновики в ветку `claude/inbox`.
  Задание — `zadanie.md`. (Или режим API: секрет `ANTHROPIC_API_KEY` — тогда всё делает дежурный.)
- **Дежурный — GitHub Actions** (каждые 30 мин, без ИИ): присылает черновики в группу модерации,
  обрабатывает кнопки и команды, публикует в канал, ставит водяной знак.

## Кнопки под черновиком
✅ в очередь · ❌ отклонить · 🕒 отложить (ночью / утром / через 3 ч / завтра / `/at 21:30`) · 💧 водяной знак
🤖 «можно без модерации» или ⚠️ что проверить — это самопроверка Claude.
Исправить текст: ответь на черновик `/edit Новый текст…`. Обычные сообщения и ответы бот не трогает.

## Команды в группе модерации
`/status` · `/night 23 7` · `/night off` · `/auto on|off` · `/gap 30` · `/nightgap 60` · `/wm on|off` · `/pause` · `/resume` · `/help`

Ночью обычная очередь ждёт утра. Выходят только отложенные и, при `/auto on`, черновики,
которые Claude отметил как безопасные.

## Настройка
1. Группа модерации: создать закрытую группу, добавить @isa_news_bot, написать что-нибудь.
2. GitHub: приватный репозиторий (запуск раз в 30 мин укладывается в бесплатные 2000 минут), загрузить все файлы (с `.github`, **без** `.env`).
3. Settings → Secrets and variables → Actions: `BOT_TOKEN`, `CHANNEL_ID` (@ilm4_info), `MOD_CHAT_ID`, `ADMIN_IDS`.
4. Actions → News bot → Run workflow.
5. claude.ai/code: подключить GitHub; в настройках окружения Default поставить **Network access: Full**;
   создать routine с репозиторием и промптом «Выполни задание из файла zadanie.md».
